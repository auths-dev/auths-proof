# Known limitations

This candidate record is intentionally incomplete:

- no immutable image or package set is bound;
- no sustained qualification time is recorded;
- no required test-evidence family is recorded;
- no independent security review is recorded; and
- no release statement is signed.

Even a future completed record will prove only the exact candidate,
configuration, schema, runtime matrix, and three named profiles in its manifest.
It will not certify customer infrastructure, identity-provider configuration,
provider policy, business intent, availability outside the measured program,
or enterprise control-plane features from specification 0039.

The local reference deployment uses deterministic effect sandboxes and
software fixture signing. Those are evaluator tools and cannot satisfy the
production custody or provider-profile evidence families.
