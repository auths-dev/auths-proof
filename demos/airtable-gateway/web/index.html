What this run can establish

This is a development demo, not protected production qualification. Simulation never reaches Airtable. Live mode touches only the fixed disposable table. Neither mode proves exclusive causation, atomic CAS, provider idempotency or PAT restriction to a single base.

A matching value with the wrong echo cannot confirm this action. Unknown writes retain their consumed operation. There is no automatic PATCH retry. The operator diagnoses and retires the run-owned records separately.
