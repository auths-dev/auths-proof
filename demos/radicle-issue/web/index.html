Why the signer is isolated

The agent never receives the Radicle signing key.

Today, automation usually gets a credential and a policy document. If either is too broad, the agent can do everything the credential can do.

Here, the agent produces evidence. The executor independently inspects Git, synchronizes Radicle, verifies the human’s Auths authorization, reserves the one allowed execution, and only then contacts the signer.
