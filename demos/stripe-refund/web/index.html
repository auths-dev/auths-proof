The credential boundary

The agent proposes parameters. It cannot call Stripe.

Stripe’s key still protects the account, but Auths prevents that key from becoming the agent’s reusable authority. The native service receives the key only after the signed action, current payment evidence, verifier configuration, and one-time claim all match.
