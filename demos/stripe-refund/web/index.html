The credential boundary

The agent proposes parameters. It cannot call Stripe.

Stripe’s key still protects the account, but Auths prevents that key from becoming the agent’s reusable authority. The native service receives the key only after the exact action, fresh payment evidence, configured policy, evaluator configuration, durable aggregate reservation, and one-time claim all match.
