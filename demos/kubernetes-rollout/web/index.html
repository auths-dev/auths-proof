The credential boundary

The agent proposes a patch. It cannot access the cluster.

Kubernetes RBAC still protects the API, but Auths prevents its token from becoming the agent’s reusable authority. The native service requests the mutation token only after the exact signed action, fresh cluster evidence, verifier policy, and one-time claim match.
