## Why the strict preflight still matters

UniqueMembers visits every original value before the typed visitor can ignore
it, including content under unit Echo variants. A duplicate key in ignored
content must therefore fail the strict pass. An already-collapsed generic JSON
map cannot witness the original member occurrence list.

Echo is parsed to support a stable refusal when an author attempts to supply
the gateway's private echo token. Its successful typed deserialization grants
no compilation or execution authority. The complete source-admission proof
must establish refusal in every author-Echo position. The new native cases
exercise path, JSON body and form body positions: ordinary ignored content
must reach EchoConflict; duplicate ignored content must fail earlier as
InvalidSource. These are authored expectations, not passed tests.

No production parser, accepted representation, serializer, source version or
error code was changed for this work. Alias inputs must normalize to their
actual typed value, which supplies the canonical preimage. Raw source byte
equality, raw JSON object equality and typed canonical preimage equality must
not be conflated.
