# Auths-Proof formal semantics paper

This directory contains the mathematical companion paper for the Lean 4
development under `formal/`.

Build it from this directory:

```sh
./build.sh
```

The script leaves a review copy beside the Markdown source and writes the final
artifact to `output/pdf/auths-proof-formal-semantics.pdf` at repository root.
All figures are native TikZ vectors embedded in the paper source so that the
mathematics, theorem discussion, and diagrams evolve together.
