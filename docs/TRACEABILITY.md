# Normative rule traceability

The checked-in corpus is generated by the Rust implementation, so it is
regression and wire evidence rather than an independent semantic oracle.
“Independent” below means a separately expressed reference relation or an
external vector source, not a second call to the same implementation.

| Rule family | Normative source | Implementation | Positive / negative vectors | Property, fuzz, or differential oracle | Portable surface |

The release gate checks specification synchronization, every stable code's
corpus coverage, a corpus vector for every inventoried kernel check site, the
authoritative fuzz inventory, canonical vectors, native conformance, and
generated Node/WASM equivalence. Independent protocol and
cryptographic review is still a human launch gate; it is never inferred from
this matrix.
